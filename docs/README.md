# Documentation

The complete design and engineering knowledge base for Age of Legends.

## Structure

| Directory                      | Contents                                                         |
| ------------------------------ | ---------------------------------------------------------------- |
| [vision/](vision/)             | Product vision, pillars, design principles and goals             |
| [gdd/](gdd/)                   | Game Design Document and per-system design                       |
| [architecture/](architecture/) | Technical architecture, networking, persistence, security        |
| [roadmap/](roadmap/)           | Roadmap, milestones, releases and backlog                        |
| [standards/](standards/)       | Coding, git, naming, review, testing and documentation standards |
| [adr/](adr/)                   | Architecture Decision Records                                    |

## Reading Order

1. [Game Vision](vision/000_GameVision.md) — why the project exists
2. [Game Pillars](vision/002_GamePillars.md) — the values every decision serves
3. [Game Design Document](gdd/000_GDD.md) — what the game is
4. [Architecture Overview](architecture/Overview.md) — how it is built
5. [Coding Standards](standards/CodingStandards.md) — how we write it
6. [Roadmap](roadmap/ROADMAP.md) — the order we build it in

## Conventions

- Documents are written in professional, third-person technical English.
- Design documents describe intent and rules; they are the source of truth for gameplay behavior.
- Decisions are recorded as ADRs and indexed in the root [DECISIONS.md](../DECISIONS.md).
