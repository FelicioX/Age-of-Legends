# Resources

## Core Resources

| Resource | Primary source      | Primary uses                                   |
| -------- | ------------------- | ---------------------------------------------- |
| Wood     | Sawmill / world     | Construction, low-tier crafting                |
| Stone    | Quarry / world      | Construction, fortification                    |
| Iron     | Mine / world        | Equipment crafting, upgrades                   |
| Food     | Farm / world        | Hero training, upkeep, consumables             |
| Gold     | Trade / quests / world | Market, acceleration, high-tier upgrades    |

## Acquisition

- **Kingdom production** — buildings generate resources over time, including offline, up to storage
  capacity.
- **World gathering** — parties harvest resource nodes across the map, actively or over time.
- **Rewards** — quests, events, dungeons and PvP grant resources.
- **Trade** — the market and direct trade redistribute resources between players.

## Storage & Protection

Storage capacity is set by warehouses and relevant buildings. A protected portion is safe from
raids; the surplus is at risk, creating a meaningful reason to spend rather than hoard.

## Sinks & Faucets

A healthy economy balances sources (faucets) with drains (sinks):

- **Faucets:** production, gathering, rewards.
- **Sinks:** construction, upgrades, crafting, acceleration, market fees, repairs, consumables.

Sink/faucet tuning is a continuous, data-driven process; see [Economy.md](Economy.md).

## Refined Materials

Beyond raw resources, professions produce refined materials (planks, ingots, components) used in
higher-tier crafting. Refinement adds economic depth and profession value. See
[Crafting.md](Crafting.md).
