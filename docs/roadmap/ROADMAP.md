# Roadmap (Detailed)

This is the detailed companion to the root [ROADMAP.md](../../ROADMAP.md). It expands each milestone
into goals and acceptance criteria. Task-level tracking lives in [Backlog.md](Backlog.md) and
[../../TASKS.md](../../TASKS.md).

## Delivery Philosophy

- **Vertical slices.** Each milestone is designed, built, tested and documented end-to-end before
  the next begins.
- **Approval gates.** A milestone closes only when its acceptance criteria pass and its
  documentation is complete.
- **Determinism first.** The simulation core and its tests precede networked and content-heavy
  features.

## Release Cadence

Pre-1.0 releases are milestone-driven. Post-1.0, the game shifts to a LiveOps cadence with regular
content updates and seasons (see [Releases.md](Releases.md) and [../gdd/LiveOps.md](../gdd/LiveOps.md)).
