# Scripts

Automation scripts for building, deploying and maintaining Age of Legends.

| Path      | Purpose                           |
| --------- | --------------------------------- |
| `build/`  | Build and packaging helpers       |
| `deploy/` | Deployment and release automation |

Most day-to-day tasks are exposed through the root `package.json` scripts and the `Makefile`
(`make help`). Scripts here cover operations that fall outside the standard task runner.
